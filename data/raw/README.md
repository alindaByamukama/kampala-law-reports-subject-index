# Raw Data

This directory contains the original, unmodified source data for the Kampala Law Reports Subject Index dataset.

**Source link:** [Kampala Law Reports Subject Index dataset](https://drive.google.com/drive/folders/1F3G_nreQiXbeGEu0eHAp3kTO8y4Lpj3L?usp=drive_link)

## Contents

- `KAMPALA LAW REPORT - SUBJECT INDEX.csv` — CSV export of the original password-protected Excel file (`KAMPALA LAW REPORT - SUBJECT INDEX.xlsx`) compiled by Jolly Kibalama. The CSV preserves the layout-oriented structure of the source spreadsheet, with one cell per row of the original visual layout rather than one row per case.

## Do not modify

This is the source of truth against which all cleaning is verified. Cleaned outputs go in `../cleaned/`. If errors are found in source data, they are documented in the project README under "Known limitations" — not corrected in place.

For source provenance (origin, access, date downloaded), see `../../PROVENANCE.md`.
